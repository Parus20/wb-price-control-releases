# wb-price-control-releases
Установщики WB Price Control. Исходный код и рабочие Excel в этом репозитории не хранятся.

- [Скачать Windows 10/11 x64 — версия 1.1.1](https://github.com/Parus20/wb-price-control-releases/releases/download/v1.1.1/WB-Price-Control-Setup-v1.1.1.exe)
- [Выпуски и контрольные суммы](https://github.com/Parus20/wb-price-control-releases/releases)

Windows: закройте прежнюю программу, запустите EXE и следуйте установщику. Python и автономный WebView2 включены. Для работы с Excel интернет не требуется. Сохранённые данные находятся отдельно от папки установки.

macOS: поддерживается только Apple Silicon (ARM). DMG будет добавлен после завершения сборки и проверки запуска.

Первый выпуск с подключённым каналом обновлений устанавливается вручную. Затем приложение проверяет новые стабильные версии при запуске; скачивание и установка требуют подтверждения пользователя.

Установщики без сертификатов Windows/Apple Developer ID. ОС может показывать предупреждения. SHA-256 доступны рядом с файлами в Releases.
